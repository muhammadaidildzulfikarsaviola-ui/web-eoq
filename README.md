# EOQ Inventory Decision System

Dashboard web sederhana untuk analisis **Economic Order Quantity (EOQ)**.

## Fitur
- Input Demand (D), Ordering Cost (S), dan Holding Cost (H)
- Perhitungan EOQ secara real-time
- Frekuensi pemesanan per tahun
- Interval antar pemesanan
- Total biaya persediaan
- Breakdown ordering cost vs holding cost
- Grafik siklus persediaan
- Halaman anggota kelompok

## Rumus utama
EOQ = √(2DS / H)

Project ini dibuat dengan HTML, CSS, dan JavaScript murni, sehingga bisa langsung dijalankan sebagai static site.
